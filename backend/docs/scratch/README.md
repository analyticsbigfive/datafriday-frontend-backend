# docs/scratch/ — notes personnelles (non versionnées)

Ce dossier est pour les brouillons personnels : explorations, notes de travail, résumés
provisoires avant validation. Tout son contenu est gitignoré **sauf ce README** — chacun peut y
écrire librement sans polluer l'historique ni la doc partagée.

**Règle** : dès qu'une note contient quelque chose d'utile au projet (une règle métier confirmée,
un bug identifié, une décision, une réponse de Bertrand), elle **ne reste pas ici** — elle migre
vers l'endroit canonique et versionné :

- règle métier / état d'un module → `datafriday-web/docs/modules/` (les pages de domaine vivent
  côté frontend, elles couvrent aussi le backend de chaque domaine)
- bug → [`docs/bugs/`](../bugs/00_INDEX.md)
- décision structurante → [`docs/adr/`](../adr/00_INDEX.md)
- question en attente de Bertrand → [`docs/QUESTIONS_A_BERTRAND.md`](../QUESTIONS_A_BERTRAND.md)

Ce dossier ne doit jamais devenir une documentation parallèle non maintenue.
