Colonne de droite — maquettes

Réorganisation de la colonne de droite : navigation compacte (Résumé + icônes tooltipées), tableau de synthèse Prédictif / Ajusté sous le résumé, et décomposition du coût en Coût Staff + Coût Matières.

  • « Résumé » : remonte en haut et ouvre l'éditeur d'événement.
  • Icônes Configuration / Réappro / Staff : activent l'onglet correspondant puis scrollent (aujourd'hui les ancres scrollent sans changer d'onglet — bug corrigé au passage).
  • Tableau synthèse : Coût = Matières + Staff, Marge recalculée sur le coût global (elle baissera vs aujourd'hui — assumé).
  • Carte « CA total (HT) » → Coût Staff · carte « Coût » → Coût Matières. Le CA vit dans le tableau.
  • Bandeau rouge (chips « scannés / configuration ») : hors lot, fix séparé.

3 · D'où viennent les chiffres

Aucune nouvelle API. Le coût staff existe déjà côté backend (GET /events/:id/staffing) — il n'est chargé aujourd'hui qu'à l'ouverture de l'onglet Staff ; il sera chargé au chargement de l'événement.
